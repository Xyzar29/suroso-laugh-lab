# Suroso Laugh Lab

A one-liner entry for the [One-Liner Laugh Lab](https://make.fun/c/u-suroso-69-one-liner-laugh-lab-6ccf3aae) bounty on [make.fun](https://make.fun): a program that writes one short funny line — the excuse a robot vacuum gives after eating a sock — to `/output/entry.txt`.

## The line

> It thought it was laundry. I thought it was lunch.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (50 characters, one line, well inside the 1–200 character gate).
